# Use of AI in this project

## Tools

- Claude (Sonnet) via Claude Code — scaffolding React components, writing the game engine logic, and generating the PWA configuration.

## What the AI did

- Generated the first draft of the decoupled simulation engine (src/game/engine.js).
- Wrote the Vite PWA plugin configuration for offline caching.
- Assisted in drafting the educational text for the Science Library.

## Human Creative Work

- Designed the core gameplay loop, resource math, and event logic.
- Created the UI/UX glassmorphism design system in Tailwind CSS.
- Curated the NASA dataset integrations and mapped them to specific game mechanics.
